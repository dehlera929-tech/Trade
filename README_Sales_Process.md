# Sales- & Kalkulationsprozess – bearbeitbare Version

Digitalisierung der handschriftlichen Tafel (Current State) als bearbeitbare RACI-/Stakeholder-Matrix.

## Dateien
- **`Sales_Process_RACI_Matrix.xlsx`** – Hauptdatei (Excel): Matrix mit eingefrorener Kopfzeile/Spalte,
  Farbcodierung (R/A/C/I), plus Tabellenblatt *Legend & Notes*.
- **`Sales_Process_RACI_Matrix.csv`** – gleiche Matrix als CSV (universell bearbeitbar, z. B. Google Sheets).

## Aufbau

**Spalten = Prozessschritte (in Tafel-Reihenfolge):**
Start → Go / No-Go → Create → Kickoff → Technical Solution → **Commercial (Pre-Sale)** → Labor Calculation →
Subcontracting → JCI Equipment → 3rd Party Equipment → Service (OBS) → Cost Review →
DoA (Delegation of Authority) → Present Quote → Negotiate → Close → Post Mortem → Commercial (Terms)

> *Commercial (Pre-Sale)* wurde nachträglich in ROT ergänzt („hatten wir zuerst vergessen") und sitzt
> hinter *Technical Solution*.

**Zeilen = Stakeholder:**
Process Sales Engineer, Customer, Seller, Sales Manager, Estimator, Offshore Engineer, Procurement,
Project Manager / Ops Manager, 3rd Party Products, Subcontractors, JCI Global Products, Legal,
Estimate Manager, EHS, Finance, Service Seller, Service TL.

**Zusatzabschnitte unten:**
- *Process Attributes*: Standardized (Yes/No), Time (W), Time (C) – z. B. Start: Time (C) = 2 hrs.
- *Tools used*: Email, Phone, SFDC, Sharepoint, THF, Excel, Customer Portal, Site Visit, Teams.

## Legende
`R` Responsible · `A` Accountable · `C` Consulted · `I` Informed · `x` beteiligt/Tool genutzt · `(decision)` Go/No-Go-Entscheidungspunkt (Raute auf der Tafel).

## Erfasste Randnotizen
- *Commercial (Terms)*-Themen: Risk, Payment Terms, Price, Delivery Times, Warranty.
- Rote Stern-Notizen an der Kopfzeile: „When is discount?", „Flexible Risk now?" (offene Fragen).
- Weitere Notizen: „2 PM Procurement", „Currently some present…", „Group Photo" (reine Erinnerung, kein Prozessschritt).

## Wichtiger Hinweis
Die **Struktur** (Schritte, Stakeholder, Abschnitte) ist vollständig und zuverlässig übernommen.
Die **einzelnen RACI-Buchstaben** sind eine *Best-Effort-Lesung* der teils schwer lesbaren Handschrift –
bitte jede Zelle gegen das Originalfoto prüfen und korrigieren. Unsichere Zellen wurden leer gelassen.
